# 04 — Hosting credentials and private access

This folder intentionally contains no password, API secret, service-account key, or Firebase console credential.

The project handoff previously contained a default administrator password. It has been removed from the repository documentation because it should not be published on GitHub. If that password is still active, change it in Firebase Authentication before sharing a public repository. Do not send Firebase service-account keys or owner credentials to an instructor; create a temporary least-privilege evaluation account if access is needed.

Share any necessary evaluation sign-in details directly with the instructor through a private channel. Keep the public repository limited to the live site URL and project configuration needed to understand the source.
